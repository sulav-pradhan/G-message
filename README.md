# G-Message

G-Message is a lightweight Electron wrapper for **Google Messages** that allows Android users to seamlessly access their messages on **macOS**.  

It provides a clean desktop experience for people who use Android phones but work on MacBooks, helping them stay connected without switching devices.

---

## ✨ Features

- 📩 Access Google Messages directly from your Mac
- ⚡ Lightweight and fast Electron-based app
- 🖥 Native macOS desktop experience
- 🔔 Desktop notifications support
- 🔒 Secure login via Google authentication
